# Releases

This repository is a **student demonstration**; there is no formal release cadence.

- **Version reference:** `nRF9151_Gateway/VERSION` (current demo: 1.0.0).
- **Changelog:** significant changes are described in commit messages and pull requests on `main`.
- **Artifacts:** users build firmware from source with nRF Connect SDK; the Frontend is run from `Frontend/server.py`.
